# MeetSieve 安装、卸载与数据保留

<!-- markdownlint-disable MD013 -->

> 适用版本：`0.1.0-alpha.1`
>
> 适用平台：macOS arm64、Windows amd64

## 1. 安装前说明

- Alpha 包尚未做 Apple Developer ID 签名、公证或 Windows 代码签名；
- 安装包内包含主程序、ONNX Runtime 动态库、第三方许可证和声纹匹配档案；
- 安装包不包含声纹模型权重，模型仍由应用在用户确认后下载；
- 卸载只删除应用本体和安装器创建的系统项，默认保留会议数据、配置、日志和用户模型。

## 2. macOS arm64

### 2.1 安装与首次启动

1. 打开 `MeetSieve-0.1.0-alpha.1-macos-arm64.dmg`；
2. 将 `MeetSieve.app` 拖入右侧 `Applications` 目录；
3. 在“应用程序”中右键点击 MeetSieve，选择“打开”；
4. 如系统阻止打开，进入“系统设置 → 隐私与安全性”，确认打开该应用；
5. 按系统提示授予麦克风等实际使用所需权限。

只有在前述方式仍无法打开、且已确认文件来自可信构建时，才使用：

```bash
xattr -dr com.apple.quarantine /Applications/MeetSieve.app
```

### 2.2 卸载

1. 完全退出 MeetSieve；
2. 在“应用程序”中将 `MeetSieve.app` 移到废纸篓；
3. 按需清空废纸篓。

上述操作不会删除：

- `~/Library/Application Support/MeetSieve`；
- `~/Library/Logs/MeetSieve`；
- 在 MeetSieve 中选择的会议工作目录。

## 3. Windows amd64

### 3.1 安装

1. 双击 `MeetSieve-0.1.0-alpha.1-windows-amd64-installer.exe`；
2. 确认安装目录，默认为 `C:\Program Files\MeetSieve`；
3. 可选取消“桌面快捷方式”和“局域网访客访问防火墙规则”；
4. 安装器会检查并安装 Microsoft Edge WebView2 Runtime；
5. 安装完成后，从开始菜单或桌面快捷方式启动。

安装和覆盖升级前必须退出 MeetSieve。安装器不会强制结束正在运行的应用。自定义
目录必须是新目录、空目录或含有 MeetSieve 有效安装标识的目录；不能选择磁盘根目录、
Windows 系统目录、Program Files 目录本身或未知非空目录。

MeetSieve 使用本机 `codex` 命令行工具。如需 Codex 功能，请确保已单独安装并登录，且
`codex` 在当前用户的 `PATH` 中可用。

### 3.2 覆盖升级

退出 MeetSieve 后直接运行新版安装器。安装器会读取原 `InstallLocation`，并只覆盖
明确的产品文件，不清空安装目录。

### 3.3 卸载

1. 完全退出 MeetSieve；
2. 在“设置 → 应用 → 已安装的应用”中选择 MeetSieve 并卸载；
3. 卸载器删除已知程序文件、快捷方式和 MeetSieve 创建的精确防火墙规则；
4. 安装目录中如有未知文件，目录和未知文件将保留。

卸载器不删除：

- `%APPDATA%\MeetSieve`；
- `%LOCALAPPDATA%\MeetSieve`；
- 在 MeetSieve 中选择的会议工作目录；
- 安装目录中非安装器管理的未知文件。

## 4. 完全清理用户数据

如确定不再需要历史会议、配置、日志和模型，请先在应用中确认当前会议工作目录，
完成必要备份后再手动删除。安装器和卸载器不会代替用户执行这一不可逆操作。

## 5. 安装包校验

发放安装包时同时提供 `SHA256SUMS.txt`。测试者应核对下载文件的 SHA-256，避免使用
传输中损坏或来源不明的安装包。
