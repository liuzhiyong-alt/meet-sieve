# MeetSieve 布局契约

<!-- markdownlint-disable MD013 -->

## 1. 桌面客户端

### 1.1 窗口

| 项目         | 规格       |
| ------------ | ---------- |
| 默认窗口     | 1280 × 800 |
| 最小窗口     | 1024 × 720 |
| 设计检查上限 | 1440 × 900 |
| 应用最大宽度 | 1440px     |

桌面客户端不设计手机导航。小于 760px 的原型折叠规则不进入正式 Wails 布局。

### 1.2 App Shell

```text
┌───────────────┬─────────────────────────────────────────┐
│ Sidebar       │ Titlebar                                │
│ 232px         ├─────────────────────────────────────────┤
│               │ Content                                 │
│               │ max 1120px                              │
└───────────────┴─────────────────────────────────────────┘
```

- Sidebar：232px；1024px 窗口时 196px。
- Titlebar：52px。
- Content：最大 1120px，桌面内边距 32px；1024px 时 20px。
- Sidebar 高度与窗口一致，底部状态固定在侧栏末端。
- 页面滚动发生在主内容区，不能让 Sidebar 随长内容离开视区。

窗口控制使用平台真实能力或平台适配组件，不在 Windows 绘制假的 macOS 三色圆点。

### 1.3 Page Header

- 左侧：可选 Eyebrow、唯一 H1、最多 66ch 说明；
- 右侧：最多一个主操作或一个页面级状态；
- 与正文间距 32px；
- 窄窗口可以上下排布，但不能隐藏主操作。

### 1.4 内容模式

| 模式     | 规格                                      | 适用                     |
| -------- | ----------------------------------------- | ------------------------ |
| Single   | 单列，最大 1120px                         | 列表、设置内容、表单     |
| Grid 2   | 两个等宽列，16px Gap                      | 首页卡片、纪要与处理状态 |
| Grid 3   | 三个等宽列，16px Gap                      | 筛选器、简短状态         |
| Split    | `1.55fr / minmax(280px, .75fr)`，20px Gap | 创建会议、会中、原始记录 |
| Settings | 176px 导航 + 内容，24px Gap               | 设置                     |

1024px 时：

- Split 收为单列；
- Settings 导航缩为 164px，Gap 16px；
- Grid 2/3 是否收列由内容长度决定，但关键状态不得被挤压。

### 1.5 会中页面

- 录音状态、计时、音频电平和结束会议入口必须在初始视区可见。
- Live Stage 位于时间线之前，不随时间线滚出后失去全部录音提示；实现时可通过
  Titlebar 持续显示录音状态。
- 时间线是主列，系统状态和参会人是辅助列。
- 当辅助列收起时，系统状态仍需可从明确入口查看。
- “保存会议……”属于会中页面状态，不跳入无上下文通用 Loading 页。

### 1.6 设置页面

- 左侧设置分类只负责定位，不承载业务说明。
- 内容 Card 最小高度 416px，避免切换标签时页面明显跳动。
- 工作目录、存储与诊断位于“通用”；ASR 和 Codex 状态在各自分类内展示。
- 工作目录修改保存后于下次启动生效；会议进行中禁止修改并显示原因。

## 2. LAN 访客 Web

LAN 页面是电脑 Web 优先、手机兼容，不复用桌面客户端 Sidebar 和 Titlebar。

### 2.1 主要尺寸

- 主要验证：1366 × 768；
- 常见桌面：1280–1920px；
- 内容容器建议不超过 1120px；
- 手机兼容验证：390 × 844；
- 768px 以下折叠为单列。

### 2.2 桌面结构

推荐结构必须先补设计确认：

```text
┌──────────────────────────────────────────────────────────┐
│ 品牌 / 会议主题 / 访客身份 / 会议状态                    │
├───────────────────────────────┬──────────────────────────┤
│ 会议消息主区                  │ 资料、上传和连接说明     │
└───────────────────────────────┴──────────────────────────┘
```

当前 `guest.html` 提供颜色、组件、身份和消息交互证据，但其 430px 单栏不是桌面 Web
最终布局金标。桌面 LAN 页面成熟度为 `design-required`。

### 2.3 手机兼容

- 只做布局折叠，不创建另一套移动产品；
- 主辅栏变为消息在前、资料与上传在后；
- 输入、上传、错误和会议结束状态必须可操作；
- 触摸目标至少 44px；
- 不横向滚动核心内容。

## 3. 安装、卸载和系统页面

- Windows 使用 NSIS Modern UI 标准简体中文欢迎、目录、组件、进度、完成和卸载页面；
- 安装器和卸载器不使用 MeetSieve App Shell，不复刻 Card、Sidebar 或 Titlebar；
- 只统一产品名称、图标、中文术语和状态文案，不开发品牌化 Web 安装界面；
- macOS 使用标准 DMG 拖放安装，不开发独立卸载器；
- Windows 与 macOS 分别使用平台文案和路径；
- Gatekeeper、防火墙和权限提示属于平台内容，不创建第二设计系统。

## 4. 滚动与固定元素

- Modal Backdrop 固定全屏，z-index 40；
- Toast 固定右下，z-index 60；
- Settings Nav 可在主内容滚动时 Sticky；
- 录音和结束入口任何尺寸下都不能隐藏；
- 不使用横向滚动容纳关键表单或状态。
