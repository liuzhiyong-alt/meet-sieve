# MeetSieve 可访问性基线

MeetSieve 新组件和新状态以 WCAG 2.2 AA 为最低目标。当前静态 UI 的已知问题先记录，
不在设计系统提炼阶段静默改变页面金标。

## 1. 对比度

- 普通文本至少 4.5:1；
- 18px 以上大文本、图标边界和非文本控件至少 3:1；
- Placeholder、Help、Meta 和 Disabled 也要在对应表面检查；
- 状态不能只靠颜色；
- Focus Ring 在所有背景上可见。

### 已知问题

当前 `#86868b`：

- 在白色背景约 3.62:1；
- 在 `#f5f5f7` 背景约 3.33:1。

因此 `12px + --ms-text-meta` 不应作为新界面的普通信息组合。当前页面先保留金标，
后续调整颜色或用途需要用户确认。

## 2. 键盘

- 所有操作可通过键盘完成；
- Tab 顺序与视觉阅读顺序一致；
- Tabs 支持 Left、Right、Home、End；
- Escape 关闭非阻塞 Modal；
- 关闭 Modal 后焦点返回触发控件；
- 不使用只有 Hover 才能发现的关键操作。

## 3. Dialog

- 使用正确 `role="dialog"` 和 `aria-modal="true"`；
- 标题通过 `aria-labelledby` 关联；
- 说明通过 `aria-describedby` 关联；
- 打开后焦点进入弹窗；
- 焦点锁定在弹窗内；
- 背景内容使用 `inert` 或等价方式禁止交互；
- 危险确认不能只靠点击遮罩关闭；
- 关闭后恢复焦点。

## 4. 动态状态

- 短暂完成反馈使用 `aria-live="polite"`；
- 阻塞错误使用 `role="alert"` 或 assertive 等价方式；
- 进度条暴露名称、当前值或不确定状态；
- 录音、ASR 重连、保存失败等变化必须可被辅助技术感知；
- 高频音频电平不逐帧播报，只提供稳定状态文案。

## 5. 控件

- IconButton 必须有可访问名称和 Tooltip；
- Switch 使用 `role="switch"` 或原生语义，并关联可见标签；
- 字段始终有可见 Label，Placeholder 不代替 Label；
- Error 位于字段下方并与字段关联；
- Disabled 控件说明禁用原因；
- 桌面普通按钮至少 40px，触摸场景至少 44px；
- 点击区域不能只有 7px 状态圆点或纯装饰图标。

## 6. 时间线与状态

- Timeline 使用有序内容语义；
- Speaker、时间和事件类型不能只靠视觉位置区分；
- AI、访客和人类发言必须有文本标签；
- 缺口、冲突和取消状态提供可读说明；
- 录音动画有静态文案 `录音中`。

## 7. Motion

- 支持 `prefers-reduced-motion: reduce`；
- 减少动态效果时关闭录音扩散动画和无必要位移；
- 不能通过闪烁表示错误；
- 加载状态不应造成布局反复跳动。

## 8. 平台

- macOS 和 Windows 使用各自清晰的系统字体回退；
- 平台窗口控件使用真实能力和正确可访问名称；
- LAN Web 同时支持鼠标、键盘和触摸；
- 手机兼容状态下不产生核心内容横向滚动。
