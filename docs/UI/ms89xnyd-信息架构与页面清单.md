# 会意（MeetSieve）信息架构与页面清单

## 1. 导航原则

- 采用“任务入口型”，应用默认进入“开始会议”；
- 不设置概览首页、数据看板或功能聚合门户；
- 全局菜单只保留：开始会议、会议记录、常用小组、设置；
- 会议详情和管理功能按需下钻，不占用全局菜单；
- 局域网访客页独立于桌面客户端导航。

## 2. 动态会议入口

全局菜单第一项随会议状态变化：

| 状态 | 名称 | 表现 |
| --- | --- | --- |
| 无进行中会议 | 开始会议 | 默认任务入口 |
| 正在录音 | 会议进行中 | 红色状态点和录音时长 |
| 正在收尾 | 保存会议… | 显示处理进度，可查看失败原因 |

用户浏览会议记录或设置时，进行中的会议入口仍然常驻，点击即可返回会议现场。

## 3. 桌面端页面

### 3.1 开始会议

包含两个连续状态，不使用多步向导：

1. **快速开始**：选择常用小组或直接添加人员，勾选本场实际参会者；
2. **会议准备**：确认会议号、可选主题、项目目录、麦克风和局域网页面。

### 3.2 会议进行中

包含：

- 会议现场：录音与转写状态、统一时间线、AI 问答、消息和资料；
- 结束处理中：录音落盘、转写收尾和 Codex 交接。

“结束处理中”是会议页面的状态，不单独增加菜单。

### 3.3 会议记录

包含：

- **会议列表**：按日期查看和搜索本机会议，展示保存与交接状态；
- **会议详情**：
  - 会议纪要；
  - 原始记录；
  - 会议消息。

附件、链接和公开 AI 回答都归入“会议消息”，不独立设置资源页面。

原始记录校对是“原始记录”的编辑模式，不独立设置页面或菜单。

### 3.4 常用小组

页内包含“小组”和“成员”两个视图：

- 小组：维护默认成员、项目目录和常用会议设置；
- 成员：维护成员资料和声纹样本。

声纹注册和样本管理在成员详情内完成。

### 3.5 设置

使用页内分区：

- 通用：会议工作目录等应用级设置；
- 录音：麦克风和录音测试；
- ASR：火山引擎凭证、连接和服务状态；
- Codex：本机 Codex 路径、连接状态和恢复能力。

不展示尚未实现的平台选项。

## 4. 局域网访客页

流程为：

1. 扫描二维码或打开短地址；
2. 从本场参会者中选择姓名；
3. 查看本场会议消息；
4. 发送文字、链接或文件。

访客不注册、不采集音频、不查看实时转写。会议结束后页面短暂只读，然后失效。

## 5. 页面数量控制

- 全局菜单：4 项；
- 桌面端核心页面：快速开始、会议现场、会议列表、会议详情、常用小组、设置；
- 准备、结束处理、校对、成员详情均作为页面状态或下钻内容；
- 不增加首页、统计、日历、Agent 市场、工作流中心等超出内部工具目标的页面。
