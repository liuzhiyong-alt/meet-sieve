# MeetSieve 本轮反馈功能规划

## 1. 当前阶段

本目录只用于确认功能范围、页面布局、文案和交互，不进入技术方案或正式开发。
HTML 中的数据均为视觉与交互夹具，不能证明真实会议、删除、查询或设置链路完成。

确认顺序固定为：

1. 确认本功能规划和可交互 HTML；
2. UI 确认后制定技术方案；
3. 技术方案确认后修改正式代码。

## 2. 功能范围

### 2.1 首页

- 保留新增的“首页”一级菜单；
- 恢复原始首页的标题、说明、双任务卡和最近会议结构；
- “快速开始”只预选现有常用小组成员，不承诺后端尚未提供的完整历史配置复用；
- “继续处理”展示最高优先级待办，并进入对应处理页面；
- 最近会议只展示少量记录，通过“查看全部”进入会议记录。

首页不是统计看板，不增加日历、趋势、会议数量指标或 Agent 工作流入口。

### 2.2 面包屑

- 面包屑固定放在应用 Titlebar，不额外占用正文高度；
- 一级页面只显示当前页面，不把“首页”作为所有页面的共同父级；
- 中间层级可以点击，当前页不可点击；
- 会议详情、纪要、原始记录、成员详情、小组详情和设置分类均显示完整路径；
- 返回成员或小组列表时恢复原来的 Tab。

### 2.3 小组与成员

- 成员列表直接提供“编辑、管理声纹、删除”，“编辑”进入可修改资料的成员详情页；
- 成员详情不再提供成员删除入口；
- 不展示归档、恢复或归档成员状态；
- 删除成员后从成员库、会前候选和当前小组移除；
- 历史会议继续保留会议发生时的姓名快照；
- 删除全部声纹是独立操作，继续保留在成员详情。

本轮 HTML 按“删除成员时同时删除显式声纹样本”展示。最终数据边界在 UI 确认后的技术
方案中定义。

### 2.4 开始会议

- “添加临时成员”位于参会人卡片标题右侧；
- 点击后使用短弹窗输入姓名；
- 临时成员只属于本场会议，并在参会人区域显示和移除；
- 参会人列表独立滚动，不因成员数量增加持续撑高页面；
- `1024 × 720` 至少完整展示 4 位成员，`1280 × 800` 展示约 5 位成员；
- 成员列表标题与第一行保持 8px 间距，成员行高度为 52px；
- 高级设置恢复两列四项布局：会议主题、会议号、麦克风、局域网访客页；
- 局域网访客页自动使用后端安全推荐的当前私网，不提供“使用的网络”选择器；无法唯一安全推荐时
  说明原因并禁止开始，用户可以关闭局域网访客页后继续；
- 展开高级设置只增加左侧卡片高度，右侧开始前检查保持自然高度；
- 删除“取得真实首帧并安全写入后，会议才会开始”说明文字；
- 真实首帧和安全写入仍是业务前置条件，不因删除说明文字而取消。

### 2.5 会议记录

- 搜索、综合状态和查询按钮使用统一高度并底部对齐；
- 下拉变化不立即查询，统一点击“查询”或按 Enter 提交；
- 修改筛选后回到第一页；
- 每页固定展示 10 场会议；
- 使用上一页、下一页和当前页信息，不展示或查询总页数；
- 分页与筛选状态应支持浏览器前进、后退恢复。

### 2.6 设置

- 设置二级菜单和右侧第一张配置卡的顶部边界对齐；
- 保留当前录音、实时转写、Codex、声纹模型和存储诊断的全部配置与操作；
- “通用”拆成“会议工作目录”和“存储与诊断”两张独立卡片；
- 保存按钮固定属于会议工作目录卡片，与存储诊断保持明确分区；
- 不再展示“当前仍在使用”和“将在下次启动时使用”的重复路径摘要；
- 保存后只显示“重启后生效”状态；
- 工作目录帮助文案精简为：
  `如需搬移会议数据，请先退出 MeetSieve，复制完整工作目录后再选择新目录。`

## 3. HTML 提案入口

- `home.html`：首页总入口；
- `start.html`：临时成员、成员滚动和高级设置；
- `records.html`：组合筛选和分页；
- `people.html`：Tab 恢复、成员列表操作和删除确认；
- `member-detail.html`：成员面包屑和无成员删除入口的详情；
- `group-detail.html`：小组面包屑与小组详情；
- `settings.html`：设置分类、顶边对齐和通用设置拆分。

## 4. 本阶段验收

- 所有页面可以从侧栏或面包屑相互到达；
- Tab、Modal、高级设置、临时成员、筛选、分页和保存反馈可以操作；
- 关键布局在 `1440 × 900`、`1280 × 800` 和 `1024 × 720` 下可用；
- 不修改正式 Vue、Go、数据库、Binding 或技术方案；
- 用户确认 UI 后，本目录作为下一阶段技术方案的页面输入。
